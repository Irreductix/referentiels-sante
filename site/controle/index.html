Contrôle FINESS

Retrouvez un établissement en tapant son nom ou son numéro, et vérifiez d'un coup une liste entière (numéros FINESS, SIRET, codes postaux) contre FINESS+, le répertoire national de l'Agence du Numérique en Santé.

Rien ne quitte votre navigateur. Une fois l'index chargé, cette page ne fait plus aucune requête : votre liste n'est envoyée nulle part, ni à nous ni à personne. Pas de cookie, pas de traceur, pas de compte. Le code de la page est public et tient en deux fichiers.

Comment lire les résultats

  • Inconnu de FINESS : le numéro n'existe pas dans le répertoire. Si sa clé de contrôle est invalide, c'est presque toujours une faute de frappe ; la colonne « pistes » propose le numéro voisin le plus probable.
  • SIRET différent : la page dit si ce SIRET appartient à un autre établissement de la même entité, ou s'il figure sur une autre ligne de votre liste (SIRET intervertis). Sinon, vérifiez lequel est à jour dans l'annuaire des entreprises.
  • Code postal : un code CEDEX dans FINESS pour la même commune n'est pas une erreur. Un code différent demande un regard.
  • Absents de la liste : les établissements que FINESS dit actifs pour vos entités juridiques et qui ne sont pas dans votre liste. À ajouter s'ils sont toujours en activité ; sinon, c'est FINESS qu'il faut faire mettre à jour, par l'ARS.

Cette page ne corrige rien et ne fait pas foi : la source reste FINESS+ (consultation officielle). Les données chargées sont l'instantané mensuel de l'ANS, publié sur data.gouv.fr sous Licence Ouverte 2.0 et converti par referentiels-sante.

Utiliser la page hors ligne

Pour un poste sans accès à internet, ou si votre service préfère ne rien charger depuis l'extérieur : téléchargez controle-finess-hors-ligne.zip, décompressez-le, ouvrez index.html dans votre navigateur, puis chargez le fichier index-finess.csv.gz du même dossier avec le bouton prévu en haut de page. L'archive est refaite le 2 de chaque mois avec le nouvel instantané.
