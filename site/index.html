Le fichier FINESS en CSV, la CCAM, la CIM-10 et les médicaments en fichiers propres

referentiels-sante télécharge les référentiels publics de la santé à leur source officielle et les convertit en CSV lisibles dans Excel, une base de données ou un script, et en JSON pour FINESS+, les nomenclatures NOS, la CIM-10 et les tarifs GHS. L'outil est libre, gratuit et tient en une commande.

npx referentiels-sante finess

Cette commande récupère le flux FINESS+ du jour et écrit dans le dossier data/finess les quelque 175 000 établissements sanitaires, sociaux et médico-sociaux (dont environ 105 000 en activité), les entités juridiques et les groupements hospitaliers de territoire.

Obtenir FINESS en CSV sous Windows, pas à pas

Pas besoin d'être développeur, ni d'installer quoi que ce soit.

Le plus simple : le fichier du mois, déjà converti

FINESS+ est converti le 2 de chaque mois à partir de l'instantané mensuel de l'ANS. La dernière archive est toujours à la même adresse : finess.zip. Décompressez-la et ouvrez etablissements.csv dans Excel. Le fichier MENTION-SOURCE.txt donne la source et la date des données. La base publique des médicaments est publiée de la même façon : bdpm.zip.

Vérifier une liste d'établissements, sans rien installer

La page Contrôle FINESS charge l'index du mois dans votre navigateur. Vous y retrouvez un établissement en tapant son nom ou son numéro, et vous y collez une liste (numéros FINESS, SIRET, codes postaux) pour obtenir aussitôt les écarts avec FINESS+ : numéro inconnu et numéro voisin probable, SIRET d'un autre établissement, établissement fermé, code CEDEX, établissements actifs absents de votre liste. Rien n'est envoyé : tout se calcule sur votre poste, et une version hors ligne existe.

Les données du jour, ou un autre référentiel : la version Windows

  1. Dans la dernière version de l'outil, téléchargez l'archive referentiels-sante-x.y.z-windows.zip. Elle contient l'outil et Node.js : rien à installer, aucun droit d'administrateur.
  2. Décompressez toute l'archive dans un dossier où vous pouvez écrire, par exemple Documents\referentiels-sante.
  3. Double-cliquez sur Convertir.cmd et choisissez FINESS+ dans le menu.
  4. Au bout d'une minute environ, le temps de télécharger 50 Mo et de les convertir, le dossier donnees\finess s'ouvre. Ouvrez etablissements.csv dans Excel. Le fichier est en UTF-8 avec séparateur point-virgule : dans un Excel en français, les accents et les colonnes s'affichent directement.

Si Node.js 22 ou plus récent est déjà installé, la commande npx referentiels-sante finess fait la même chose depuis PowerShell, dans un dossier data\finess (si PowerShell refuse l'exécution de scripts, tapez npx.cmd à la place de npx).

Derrière le proxy d'un établissement, les téléchargements peuvent être bloqués. Faites le premier essai depuis un poste avec un accès direct à internet, ou voyez les réglages avec votre DSI.

Anomalies de FINESS+

L'outil recopie la source sans la corriger. Deux défauts de FINESS+, signalés à l'ANS, ont été déclarés corrigés le 5 octobre 2026 :

  • Dans 1 364 adresses d'établissements du fichier du 14 septembre 2026, la séquence « TH » avait été remplacée par « E » : « rue de la Catherinette » était devenue « Caeerinette », « Thoiry » « Eoiry ». Quelques adresses restent touchées dans le fichier du 13 octobre, comme « rue Paul Bereelot ». Ticket de l'ANS.
  • Pour la majorité des adresses, les coordonnées projetées et géographiques étaient permutées entre leurs colonnes. Elles sont à leur place pour tous les établissements géolocalisés de métropole dans le fichier du 13 octobre. Ticket de l'ANS.

Les fichiers produits à partir d'un flux antérieur au 6 octobre 2026, dont le fichier du mois publié en octobre, contiennent encore ces défauts.

La comparaison complète avec l'ancienne extraction, champ par champ, est détaillée dans la documentation FINESS.

Questions fréquentes

Je cherche un fichier finess.csv : pourquoi ne plus le trouver sur data.gouv.fr ?

L'extraction FINESS diffusée en CSV sur data.gouv.fr n'est plus mise à jour : ses dernières données datent du 4 mai 2026. Depuis le 20 juillet 2026, FINESS est publié par l'Agence du Numérique en Santé sous le nom FINESS+, en JSON. referentiels-sante reconstruit un CSV à partir de ce nouveau flux, y compris au format de l'ancien fichier. Le fichier du mois, déjà converti, se télécharge directement.

Les données sont-elles à jour ?

Pour FINESS+, oui : chaque exécution télécharge le flux du jour, et le fichier structures-resume.json indique la date exacte des données. Le fichier du mois, lui, contient l'instantané mensuel de l'ANS, daté dans MENTION-SOURCE.txt. Pour la CCAM, la page de téléchargement de l'Assurance Maladie est lue à chaque exécution. Pour les tarifs GHS, la page de campagne de l'ATIH est lue à chaque exécution. Pour la CIM-10, l'outil connaît les éditions que l'ATIH publie au format ClaML, aujourd'hui la CIM-10 FR 2025 : l'édition 2026 n'est diffusée qu'en PDF, elle sera ajoutée dès la publication de son fichier ClaML.

Puis-je réutiliser les fichiers produits ?

FINESS+ et la base publique des médicaments sont publiés sous Licence Ouverte : la réutilisation est libre, en citant la source et la date. Les autres référentiels ont leurs propres conditions, détaillées dans la page des sources et licences. L'outil télécharge les données à la source au moment où vous le lancez. Seuls FINESS+ et la base des médicaments sont aussi republiés déjà convertis, chaque mois, avec leur mention de source ; les autres référentiels ne sont jamais republiés, hormis les libellés et agrégats des nomenclatures NOS inclus dans les fichiers FINESS.

Faut-il des droits d'administrateur ?

Non avec la version Windows : l'archive contient Node.js et s'utilise après une simple décompression. Pour installer Node.js soi-même, en général oui. L'outil lui-même ne demande aucun droit particulier et n'installe aucune autre dépendance.

Et si une source change de format ?

Les sources sont des pages web, pas des interfaces stables. Une vérification automatique tourne chaque lundi depuis les serveurs de GitHub : elle contrôle que les pages et les fichiers de chaque source répondent encore, et ouvre un ticket sur le dépôt en cas de panne. La CCAM fait exception : le site de l'Assurance Maladie refuse ces serveurs, elle se vérifie depuis un poste. Vous pouvez la lancer vous-même avec npx referentiels-sante verifier.

Pour les développeurs

Le paquet s'utilise aussi comme bibliothèque Node.js. Il expose les convertisseurs et un lecteur JSON en flux qui parcourt les 751 Mo de FINESS+ objet par objet, sans charger le fichier en mémoire.

import { finess, nos, lireCollection } from 'referentiels-sante';

for await (const entite of lireCollection('finess-structures.json.gz', 'pmej')) {
  console.log(entite.informationsGeneralesPMEJ.numFinessPm, entite.ege.length);
}

const categories = await nos.chargerTable('TRE_R66-CategorieEtablissement');
nos.indexLibelles(categories).get('355'); // 'Centre hospitalier (CH)'
